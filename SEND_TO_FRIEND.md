### Mode 1: 💡 Get Chart Recommendations
**The Problem:** "I have data but don't know which chart to use..."

**The Solution:** Just describe what you want to show in plain English!

**Example:**
```
You type: "Compare monthly sales across regions"

App instantly recommends:
1. Bar Chart - Best for comparing values
2. Grouped Bar Chart - For multiple metrics
3. Column Chart - For time-based comparisons

Plus tells you EXACTLY how to design each chart:
- What colors to use
- How to set up axes
- Where to place labels
```

**Use When:** You need guidance on data visualization

